# EKPS 清洗分段器

Dify **知识流水线**（1.9.0 起）的数据处理工具，面向中文制度、规章类文档。

接在文本提取器（如 Dify Extractor）后面。包含两个工具：

- **去噪并按条款分段**：`result` 连到**通用模式**的知识库节点
- **去噪并按条款父子分段**：一条规定做父块、其中每一句做子块（表格每行做子块并带表头），`result` 连到**父子模式**的知识库节点

已在 Dify 云版知识流水线中实测（文件上传 → Dify Extractor → 本工具 → 知识库）。

## 做什么（一次处理一份文档）

1. **去噪**：封面落款（单独成行的机关名、文号、日期）、分隔线、页码、目录行、主送机关、标题行。含金额、期限、"不得""禁止"等字样的行一律保留。
2. **按条款分段**：遇"第X条"开新段，后续段落并入该条；"第X章"和 Markdown 标题记进上下文头，不单独成段；Markdown 表格连同表题整张成段，长表按行切开、每块重复表头；没有条款编号时一段一块。
3. **加上下文头**：每段开头写 `【《标题》｜文号｜施行日期｜所属章节】`，单独命中一段也知道出自哪份、哪个版本。

## 安装与配置

1. 从 Dify 插件市场安装（需要 Dify 1.9.0 或以上），不需要任何凭据或密钥。
2. 在知识流水线里，把"去噪并按条款分段"（或父子分段版）接在文本提取器后面。
3. "输入文本"选提取器的文字输出；知识库节点的分段输入选本工具的 `result`。
4. 发布流水线前，先用"测试运行"预览分段效果。

## 参数

| 名称 | 必填 | 说明 |
| --- | --- | --- |
| `input_text` | 是 | 一份文档的文字 |
| `title` | 否 | 文档标题；不填时取开头第一个像公文标题的行 |
| `max_length` | 否 | 每块最大字数，含上下文头和表题（默认 500） |
| `context_header` | 否 | 是否加上下文头（默认加） |

## 不做什么

一次只看一份文档，所以新旧版本替代、跨文件去重、文件之间的冲突都做不了。整库体检与净化见 EKPS 本地工具。
